# Security

Please report security problems privately through GitHub: on the repo's **Security** tab choose **Report a vulnerability** ([direct link](https://github.com/hearthbit/gamehearth/security/advisories/new)). Do not open a public issue for them.

Helpful are the affected part (server, client, SDK, dev tool), the version or commit, the steps to reproduce and what an attacker gains. You will get an answer as soon as possible; Gamehearth is maintained in spare time, so please allow a few days.

What Gamehearth defends against, and what it deliberately does not (for example: adding a catalog means trusting its games), is described in [docs/design.md](docs/design.md), above all in "Isolation in the client", "Sandbox on the server", "Accounts and guests" and "Game packages and catalogs".
